# GitHub Profile Setup

1. Create a repository named exactly `Lakshmanpolepalli003` under your GitHub account.
2. Copy all files and folders from this package into that repository.
3. Commit and push `README.md`, `assets/`, and `github-snake.yml`.
4. Move `github-snake.yml` to `.github/workflows/github-snake.yml`.
5. Enable GitHub Actions and run the workflow once manually.
6. The snake workflow publishes generated SVGs to the `output` branch.
7. Keep `assets/character.png` in the repository because the animated local SVGs embed it directly.
